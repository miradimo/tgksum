# AI Telegram News Digest 🚀

Интеллектуальная система для автоматического сбора, классификации и суммаризации новостей из Telegram-каналов с использованием локальных языковых моделей (Ollama).

## 📋 Обзор

Проект позволяет превратить "информационный шум" из десятков подписок в структурированный дайджест. Система собирает посты через пользовательский аккаунт (Telethon), анализирует их содержимое с помощью нейросетей, группирует по темам и публикует краткие выжимки (карточки) в соответствующие топики вашей супергруппы.

## ✨ Основные возможности

- **Сбор медиа и текста**: Загрузка постов и изображений из выбранных каналов.
- **Умная классификация**: Автоматическое распределение новостей по категориям (`Военные действия`, `Геополитика`, `Технологии/AI`, `Финансы` и др.) с помощью модели `Qwen 2.5 7B`.
- **Интеллектуальное суммаризация**: Генерация кратких и содержательных карточек новостей с помощью `Qwen 2.5 14B`.
- **Управление через Telegram-бота**: Удобный интерфейс для включения/выключения каналов, синхронизации списка подписок и ручного запуска пайплайна.
- **Публикация в топики**: Автоматическая отправка дайджестов в конкретные темы (threads) супергруппы Telegram.

## 🛠 Стек технологий

- **Язык**: Python 3.10+
- **Telegram API**: Telethon (UserBot API)
- **Bot API**: Aiogram 3.x (Admin Interface & Publisher)
- **AI Engine**: Ollama (локальный запуск моделей)
- **Database**: SQLite (aiosqlite)
- **Models**: Qwen 2.5 (7B для классификации, 14B для суммаризации)

## 🚀 Быстрый старт

### 1. Подготовка окружения
Убедитесь, что у вас установлен [Ollama](https://ollama.com/) и скачаны необходимые модели:
```bash
ollama pull qwen2.5:7b
ollama pull qwen2.5:14b
```

### 2. Установка зависимостей
```bash
pip install -r requirements.txt
```
*(Примечание: создайте файл requirements.txt, если его еще нет, включив туда aiogram, telethon, aiosqlite, ollama)*

### 3. Настройка конфигурации
Отредактируйте файл `config.py`, указав свои данные:
- `API_ID` и `API_HASH`: Получите на [my.telegram.org](https://my.telegram.org)
- `BOT_TOKEN`: Получите у @BotFather
- `CHAT_ID`: ID вашей супергруппы, куда будут идти посты.
- `TOPIC_THREADS`: ID топиков внутри группы для каждой категории.

### 4. Первый запуск и авторизация
Для авторизации в качестве пользователя (для сбора постов):
```bash
python run_pipeline.py --sync
```
Следуйте инструкциям в терминале для ввода номера телефона и кода подтверждения.

### 5. Запуск бота-управления
```bash
python bot_controller.py
```

## 📂 Структура проекта

- `bot_controller.py` — Главный интерфейс управления системой через Telegram.
- `telethon_collector.py` — Модуль сбора данных из каналов.
- `classifier.py` — Логика классификации постов по категориям.
- `summarizer.py` — Генерация кратких выжимок и формирование карточек.
- `publisher.py` — Модуль отправки готовых новостей в Telegram.
- `dynamic_topics.py` — Обработка новостей, не попавших в основные категории.
- `database.py` — Работа с базой данных SQLite.
- `run_pipeline.py` — Скрипт для запуска полного цикла обработки в консоли.

## 🤖 Использование

1. Запустите `bot_controller.py`.
2. В боте нажмите **"🔄 Синхронизировать каналы"**, чтобы подтянуть список ваших подписок.
3. В разделе **"📑 Список каналов"** выберите те, которые нужно отслеживать (отметьте 🟢).
4. Нажмите **"🚀 Запустить полный дайджест"** для начала сбора и обработки.
